# ML Fundamentals

This section contains my experiments with fundamental machine learning concepts and algorithms.

The goal is to understand how core ML methods work from mathematical formulation to practical implementation, and to
connect implementations written from scratch with the abstractions provided by modern machine learning libraries and
frameworks.

## Learning focus

The experiments in this section focus on:

* Mathematical formulation of machine learning models.
* Loss functions and optimization.
* Implementations from scratch with NumPy.
* Comparison with standard implementations provided by libraries such as scikit-learn.
* Connections between classical machine learning concepts and PyTorch training workflows.
* Model evaluation and analysis.
