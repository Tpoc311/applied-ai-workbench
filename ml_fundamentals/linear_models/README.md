# Linear Models

This section contains my experiments with linear models for regression and classification.

The goal is to understand how linear models work, how their objective functions define the learning problem, and how
their parameters can be estimated using analytical solutions or iterative optimization methods.

## Learning focus

Linear models provide a simple setting for studying many fundamental machine learning concepts:

* Model parameters and predictions.
* Loss and objective functions.
* Analytical parameter estimation.
* Gradient-based optimization.
* Regression and classification.
* Model evaluation.
* Connections between NumPy implementations, scikit-learn estimators, and PyTorch training workflows.

## Available models

* [Linear Regression](./linear_regression) - Linear regression implemented using the normal equation, gradient descent
  with NumPy, scikit-learn, and PyTorch.
* [Logistic regression]() - Logistic regression implemented using the normal equation, gradient descent
  with NumPy, scikit-learn, and PyTorch.
